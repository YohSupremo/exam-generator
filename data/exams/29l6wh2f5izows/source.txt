●​ Fundamental Differences (Linux vs. Windows): 
1.​ Linux is yours, Windows is still theirs. 
2.​ Linux needs root privileges to be able to execute codes. 
3.​ Linux does not need any anti-virus software (No OS is totally secure). 
4.​ Windows users are encouraged to pay for software that is only about 20% effective and 
severely limits performance. 
5.​ Linux uses a centralized software approach, Windows does not. 
6.​ Most new-user-friendly Linux distributions come with the most needed software already 
installed. 
7.​ Linux software is installed in predetermined directories; it cannot be moved or installed 
elsewhere. 
8.​ Proprietary drivers are available through online repositories; Windows drivers include 
unwanted software or adware. 
9.​ Linux updates everything at once and never restarts without permission; Windows 
updates select software and restarts without consent. 
10.​Linux uses /dev for drives; Windows uses alphabet letters. 
 
●​ Mistakes from New Linux Users: 
1.​ Choose wrong hardware. 
2.​ Choose wrong Linux distributions. 
3.​ Linux is not Windows (expectation). 
4.​ User uses Google to find software. 
5.​ User doesn't take time to learn Linux.
